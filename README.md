# Sistema-controle-de-contas

Primeiro projeto de portfólio desenvolvido para praticar persistência de dados em Python utilizando JSON.

## Funcionalidades atuais

- Cadastro de contas
- Validação de dia e mês de vencimento
- Controle de contas fixas
- Cálculo do total a pagar
- Armazenamento em arquivo `contas.json`
- Leitura automática das contas já salvas
- Listagem formatada das contas

## Tecnologias utilizadas

- Python 3
- Módulo `json`

## Como executar

```bash
python main.py
```

## Estrutura do projeto

```text
controle-contas/
│
├── main.py
├── contas.json
```
